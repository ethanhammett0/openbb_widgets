# OpenBB Revista Workspace Extension

This extension integrates Revista Property Intelligence into the OpenBB Workspace.

## Components

- **Search**: `openbb_revista.search`
- **Scorecard**: `openbb_revista.scorecard`
- **Interactive Earth**: `openbb_revista.interactive_earth`
- **Market Trends**: `openbb_revista.market_trends`
- **Market Balance**: `openbb_revista.market_balance`
- **Activity Proxy**: `openbb_revista.activity_proxy`
- **Benchmarker**: `openbb_revista.benchmarker`
- **Stakeholders**: `openbb_revista.stakeholders`
- **Models**: `openbb_revista.models`

## Installation

```bash
pip install .
```
